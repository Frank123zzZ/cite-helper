# 引用助手（Cite Helper）

在任何网页上点插件图标（或按 Alt+Shift+C），生成 MLA 9 / APA 7 引用（默认 MLA）：文末参考文献 + 文中引用（括号式和叙述式），可填页码，一键复制（粘贴到 Word / Google Docs 时保留斜体）。

## 安装
1. 打开 `chrome://extensions`，打开右上角「开发者模式」
2. 点「加载已解压的扩展程序」，选择这个 `cite-helper` 文件夹
3. 点插件里的 ⚙，填入 Anthropic API Key，选择模型（Sonnet 5.5 更快，Opus 5.5 更准）

## 它怎么找信息
1. **网站自带的引用**：DOI 登记信息（doi.org）、网站的 RIS / BibTeX 导出、网站的「Cite」窗口（会自动点开并把内容复制出来）、citation_* 元数据
2. **Claude 整理**：把上面这些和页面文字交给 Claude，在后台整理出作者、标题、期刊、卷期页码、日期等
3. **信息不全时自动搜索**：如果还缺作者、日期、出处等，插件会直接让 Claude 上网搜索补全（不用再问），完成后在引用下方标出「Claude 补全了：…／更正了：…」，编辑表单里这些字段也会标成橙色。任何时候也可以点「搜索补全」再搜一次
4. 不对的地方点「编辑」直接改，引用会实时更新

## 可信度
填了 Key 后，Claude 会根据来源类型（同行评审期刊、官方机构、新闻、博客、营销页面等）、出版方声誉、作者是否署名及其专业背景、有没有证据和参考文献、时效性、商业或立场倾向，给文章打一个可信度：**高 / 中 / 低**，显示在引用下方，附一句理由和 2–3 条要点。这只是 AI 的参考判断，重要的引用请自己再核实。

不填 Key 也能用，只是不会经过 Claude 整理，也不会自动搜索补全。
